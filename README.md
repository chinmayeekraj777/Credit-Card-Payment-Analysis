# Credit Card Payment Analysis

## Project Overview
This project analyses credit card customer data to understand payment defaults and identify patterns in customer repayment behaviour. Tableau is used to create visualizations and an interactive dashboard.

## Objectives
- Analyse credit card default status.
- Study default patterns across different age groups.
- Compare default rates across education categories.
- Present insights through a Tableau dashboard.

## Tools Used
- Tableau
- Microsoft Excel / CSV
- GitHub

## Visualizations
1. Credit Card Default Status of Customers
2. Default by Age Group
3. Default by Education
4. Credit Card Default Risk Analysis Dashboard

## Dataset
The project uses the **Default of Credit Card Clients** dataset from the UCI Machine Learning Repository.

Dataset source: https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients

## Conclusion
The dashboard helps explore customer default patterns across age groups and education categories. These insights can support better understanding of credit risk and repayment behaviour.
